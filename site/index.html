sc-agent

A Synaptic Canvas component.

Home Announcements

sc-agent holds the Synaptic Canvas AI team assets: Claude, Codex and Cursor agent prompts, orchestration skills, beads integration and plan anchoring for Rust development workflows. The assets are version-controlled so every harness runs the same text, and they are installed into consuming repositories rather than copied by hand.

The ATM team sc-ai (ai-lead, ai-qa, tai, lai, sai) drives sprint work from this repository.
