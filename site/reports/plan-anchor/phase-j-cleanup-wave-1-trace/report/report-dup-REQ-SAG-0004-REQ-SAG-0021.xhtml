REQ-SAG-0004 Session log identity: repo, agent role, project and tool

Statements

  • Every session row MUST carry its identity.
  • sc-agent MUST refuse every query whose identity is not valid.
  • In a git repository, a query's repository MUST be that repository's origin name.
  • Outside a git repository, a query's repository MUST be `local/<host>/<folder-name>`.
  • A query's project MUST be the project that REQ-SAG-0021 resolves for it.
  • The `decidr` CLI MUST accept an agent role from its user.
  • The Python bindings of sc-agent MUST accept an agent role from their caller.
  • A generated consumer client MUST set the agent role to the client's product name.
  • A generated consumer client MUST NOT let its user set the agent role.

REQ-SAG-0021 The project/phase setting is required and shared

Statements

  • The `project` setting MUST be resolved through every project layer.
  • The PyO3 bindings MUST take `project` from the first project layer that sets it.
  • In the PyO3 bindings, a `project` argument MUST take the place of the `--project` flag layer.
  • A session with no project/phase MUST be refused with an error.
  • When no project layer sets `project`, a session write MUST NOT send a session.
  • When no project layer sets `project`, a session write MUST NOT write a session.
  • `project` MUST NOT have a built-in default.
