Justification

"In decider mode, answers from each covered model MUST conform to the required schema." stays: it serves ANC-013's check that each wire format receives schema-valid JSON. The six statements cut here go beyond ANC-013, which asks for an LLM trait and one implementation per wire format. Two of them are provider plumbing and are deleted outright with no anchor: the structured-output request, and passing inputs to the provider and returning its errors. The code documents the structured-output request in crates/sc-agent/src/lib.rs. Neither is an owner rule. Two are believed needed and go to the owner as an anchor: the model generates its own `probabilities` and `confidence`, and a response that fails the schema returns `decision.schema_mismatch`. The code documents the error in crates/sc-agent/src/lib.rs, and the first rule keeps Jev and LLM answers comparable. All statements date from 8f41793e (2026-11-25), before ANC-013 (2026-11-26).
