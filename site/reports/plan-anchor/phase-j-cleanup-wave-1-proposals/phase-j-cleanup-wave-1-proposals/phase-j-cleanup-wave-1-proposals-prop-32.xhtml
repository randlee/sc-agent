Change

  • Delete from REQ-SAG-0801: “`sc-agent` MUST send requests to a local decision runner in the Jev API format.”
  • Keeps: “For decision requests, every decision provider receives the same Jev API request body. `sc-agent` holds one provider table and one model table; the model table is its built-in rows plus the rows configuration adds (REQ-SAG-0102), so a new model works without a release. Decision providers implement one decision trait, and LLM providers one LLM trait (JSON in, JSON out). Jev implements the decision trait over SystemOne. One type per wire format, OpenAI-compatible chat/completions and Anthropic-compatible Messages, implements both traits and is shared by every provider of that format. Before a send, the decision implementation adapts the request to its wire format; the reply is decoded back into a Jev API response. Callers open one `Run` per command (created, used for its calls, then disposed) and use its two methods, `send` for one request and `send_batch` for many; the worker threads, holdoff, cancellation and session logging live behind them.”

Clears

  • ADR-SAG-0001 restates REQ-SAG-0801 statement 5 (duplicate)

Justification

ADR-SAG-0001 decides every decision provider, local runners included, receives the one Jev API request body; REQ-SAG-0801 restates that choice (Correcting duplicates rule 3). Cutting the ADR sentence would remove its whole decision. REQ-SAG-0801's stub-local-runner acceptance criterion loses its statement; checked when applying.
