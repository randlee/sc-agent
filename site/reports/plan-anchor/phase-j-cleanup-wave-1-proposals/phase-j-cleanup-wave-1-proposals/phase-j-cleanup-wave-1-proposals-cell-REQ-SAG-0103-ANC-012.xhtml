REQ-SAG-0103 × ANC-012 — related

sc-agent

Anchor

sc-agent's decision providers must implement one decision trait, with one implementation per wire format (Jev TypeSafe systemone, OpenAI-compatible chat/completions, Anthropic-compatible Messages), and every provider that speaks a wire format must use that format's implementation, so adding a provider needs no new code or hard-coding.

Owner said: “there should be implementations of the decison trait for jev, openai-sdk, anthropic-sdk and compatible providers. we will also need a llm-trait or similar to enable json-in/json-out llm behavior for open-ai-sdk, anthropic-sdk and compatible providers. i.e. all providers w/ compatible api should use the same impelemntation.”

Scope: adds or changes decision providers, provider dispatch or the provider table in sc-agent

Record statements

  • A model-table row MUST store its provider in a field separate from its model.
  • A request MUST carry the model id stored in the selected model-table row.
  • sc-agent MUST be able to send requests through Together.
  • sc-agent MUST be able to send requests through OpenRouter.
  • When configuration names a provider for a model, sc-agent MUST send that model's requests to that provider.
  • When no provider is configured for a model, sc-agent MUST prefer a provider that needs no key over one that needs a key.
  • When no provider is configured for a model and every provider serving it needs a key, sc-agent MUST use the first of them whose key is found.
  • The provider that sends requests to the OpenAI API MUST have the name `openai`.
  • A short name MUST NOT encode its provider.
  • A request MUST NOT require the caller to name a provider.
