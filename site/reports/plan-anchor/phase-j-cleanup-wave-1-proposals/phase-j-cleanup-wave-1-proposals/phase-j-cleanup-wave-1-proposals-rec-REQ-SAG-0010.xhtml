REQ-SAG-0010 No sleep()

REQ · sc-agent · Approved · version 0.2.1

Statements

The source code of this project MUST NOT call any sleep function.

Requirement

`sc-agent` is this project. A sleep function includes `std::thread::sleep`, `std::thread::sleep_until` and `tokio::time::sleep`.

Rationale

A sleeping thread cannot react to cancellation or new work; waits are made on events or deadlines that cancellation can end. This requirement is met by a timed wait that cancellation can end, such as a wait on a channel or condition variable. It does not require a clock abstraction or an injected time source. Owner ruling (2026-11-20), Rand Lee: "No sleep (is async requirement)."

Acceptance criteria

A workspace search of non-test source finds no call to a sleep function.
