## REQ-SAG-0502: sc-ai can launch any LLM

**Status:** Draft  

### Requirement Statement

**MUST statements:**

- sc-ai MUST be able to launch any LLM, not only decision models.

### Rationale

Decision models are a small part of what sc-agent does.

### Success Criteria

**Acceptance Criteria:**

- [ ] sc-ai sends a request to a non-decision LLM selected by short name and returns its response.
