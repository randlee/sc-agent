ADR-SAG-0002 Session logs are JSONL first, then SQLite with server sync

Decision

For the MVP, session logs are JSONL under `<log_root>/sessions/<repo>/<agent_role>/<project>/` (ADR-SAG-0021). Later they load into a local SQLite database that syncs to a server for long-term storage. Every row carries its own `session_id`, `repo`, `project` and `agent_role`. All sessions of one repo, agent role and project are appended to one file in that directory; a project lasts under a day to several days.

REQ-SAG-0005 Session log rows and run links

Statements

  • Session logs MUST be written as JSONL.
  • For every query whose model call succeeded, sc-agent MUST append a session row to the query's session log.
  • sc-agent MUST NOT append more than one session row for one query.
  • sc-agent MUST NOT append a session row for a failed call; the error goes to the general log.
