ANC-005

Statement

In production runs, every logger sc-agent creates by default, not injected by a caller, must write under the configured log root with a fixed folder and file name, so tools can find the logs.

Owner said

I mandated - that all default loggers created in production have root/folder/file naming conventions specified.

Scope

adds or changes creation of a default sc-observability Logger in sc-agent, decidr or the client template

Deterministic check

test: default_logger(name) path == `<log_root>/logs/<name>.log.jsonl`; session sink path == `<log_root>/sessions/<repo-id>/<role>/<project>/sessions.jsonl`
