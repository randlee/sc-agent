REQ-SAG-0201 Jev API types live in sc-agent

REQ · sc-agent · Approved · version 0.2.1

Statements

  • `sc-agent` MUST define every type that maps to the Jev API.
  • `sc-agent` MUST cover 100% of the Jev API request and response.

Requirement

Definitions: The Jev API is the TypeSafe decision API (`POST /v1/systemone`, `GET /v1/models`) with the `choice`, `score`, `noul` and `box` question and answer types. A type maps to the Jev API when it represents part of a Jev API request or response.

Rationale

The first requirement for sc-agent is to expose the TypeSafe API, so any Jev query can be run through it. Owner ruling 2026-11-21: records follow docs/plans/reduction-plan.md.

Acceptance criteria

  • Unit tests verify that each request and response example in the TypeSafe API documentation (https://docs.typesafe.ai, OpenAPI 0.2.0 at https://api.typesafe.ai/openapi.json), for all four question types, round-trips through `sc-agent` without loss.
  • No crate other than `sc-agent` defines a type that maps to a Jev API field.
