ANC-015

Statement

A rule that applies to every decidr-based tool (logging, model resolution and the like) must be specified only in sc-agent's records; a derivative tool's records (judge-jev, plan-anchor and others) must not restate it and give only the tool name and the tool's own behaviour, so each rule has one source.

Owner said

judge-jev and plan-anchor simply supply tool name and follow the rules established for all decidr based tools

Scope

adds or changes REQ/NFR/ADR records of judge-jev, plan-anchor or another sc-agent-based tool

Deterministic check

no derivative-tool record states log placement, model resolution, consent, retries or result-line fields; each points to the sc-agent record

Kind

prohibition
